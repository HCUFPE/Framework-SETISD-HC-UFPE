# Glossário

Este glossário reúne termos, siglas e conceitos utilizados nos documentos do projeto.

## Termos Operacionais

- **UACAP**: Unidade de Anatomia Patológica. Área do hospital responsável pelo processamento, análise e arquivamento de peças patológicas.
- **Triagem**: Etapa inicial de recepção da peça patológica, onde o frasco é identificado, o paciente é vinculado e a primeira etiqueta é gerada.
- **Macroscopia**: Fase em que o patologista ou macroscopista descreve a peça, define a clivagem e gera os cassetes para processamento.
- **Processamento Técnico**: Conjunto de etapas laboratoriais que inclui processamento de tecido, inclusão em parafina, corte e coloração.
- **Microscopia**: Etapa de análise das lâminas pelos residentes e médicos patologistas, incluindo laudo prévio e laudo final.
- **Retrabalho**: Pedido de complementos ou nova análise técnica solicitado pelo patologista após revisão inicial, frequentemente envolvendo imunohistoquímica.
- **Visão Unificada**: Tela que cruza dados locais do sistema com dados clínicos importados do AGHU, permitindo rastreabilidade completa.

## Itens da Árvore de Amostras

- **Frasco**: Recipiente físico original recebido na triagem; representa a peça matriz que dá origem a cassetes.
- **Cassete**: Fragmento clivado a partir do frasco durante a macroscopia; cada cassete é um container para blocos de parafina.
- **Bloco de Parafina**: Bloco sólido que contém o tecido processado e fixado; cada bloco origina várias lâminas.
- **Lâmina**: Fenda de vidro com a secção de tecido cortada do bloco; unidade final analisada microscopicamente.

## Termos de Dados e Integração

- **Número de Solicitação**: Identificador interno único gerado pelo sistema para cada exame ou peça recebida.
- **Prontuário**: Código de identificação do paciente no AGHU.
- **Sync / Sincronização**: Processo de importação de dados do AGHU e exportação de dados de macroscopia e laudos.
- **Cache Local**: Armazenamento temporário em PostgreSQL dos dados demográficos e de exame obtidos do AGHU, usado para garantir operação offline.
- **Anti-Corruption Layer (ACL)**: Camada de isolamento entre o sistema local e o AGHU para proteger o modelo interno de inconsistências e mudanças externas.
- **Provider**: Componente de software responsável por abstrair acesso a dados ou serviços externos (banco, AGHU, impressora, etc.).

## Termos de Segurança e Conformidade

- **LGPD**: Lei Geral de Proteção de Dados. Legislação brasileira que regula o tratamento de dados pessoais e sensíveis.
- **AD / Active Directory**: Serviço de diretório Microsoft usado para autenticação e gerenciamento de identidades no ambiente hospitalar.
- **LDAP**: Protocolo de acesso a diretórios, usado para autenticação de usuários.
- **JWT**: JSON Web Token. Formato de token usado para autenticação de sessão entre frontend e backend.
- **Auditoria**: Registro de ações e consultas sensíveis, incluindo usuário, IP, timestamp e recurso acessado.
- **Soft Delete**: Técnica de exclusão lógica em que o registro não é removido fisicamente, mas marcado como inativo.

## Termos Técnicos e de Arquitetura

- **Vue 3**: Framework JavaScript para construir interfaces web reativas.
- **Vite**: Ferramenta de build rápida usada para aplicações Vue e outras stacks front-end.
- **FastAPI**: Framework Python para construção de APIs REST assíncronas.
- **PostgreSQL**: Sistema de gerenciamento de banco de dados relacional usado para persistência local.
- **WebSocket**: Canal de comunicação bidirecional usado para notificações em tempo real.
- **HID**: Human Interface Device, padrão de dispositivos como leitores de código de barras que se comportam como teclados.
- **QR Code**: Código de barras bidimensional usado para identificação rápida de frascos, cassetes, blocos ou lâminas.
- **ZPL/EPL**: Linguagens de impressão usadas por impressoras térmicas Zebra/Argox.
- **SPA**: Single Page Application. Aplicação web que carrega uma única página HTML e atualiza o conteúdo dinamicamente.
- **Injeção de Dependência**: Padrão arquitetural que permite desacoplar criação de objetos de sua utilização.
- **Routers -> Controllers -> Providers**: Estrutura de organização de código exigida pelo framework appstart.

## Siglas

- **RF**: Requisito Funcional.
- **RNF**: Requisito Não Funcional.
- **UC**: Caso de Uso.
- **MVP**: Minimum Viable Product.
- **ACL**: Anti-Corruption Layer.

## Termos de Rastreabilidade

- **Histórico de Movimentação**: Registro de todas as transições de status de frascos, cassetes, blocos e lâminas.
- **Status**: Estado atual de um item no fluxo (por exemplo, "Aguardando Macroscopia", "Em Processamento", "Liberado").
- **Fila**: Conjunto de itens agrupados por etapa para processamento (macroscopia, processamento técnico, microscopia).

## Outros Conceitos

- **Impressora Térmica**: Equipamento usado para gerar etiquetas resistentes com QR Code para identificação física.
- **Leitor de Código de Barras / QR Code**: Dispositivo que captura o identificador físico do item e o envia ao sistema.
- **Loja de Tokens / Refresh Token**: Mecanismo para manter sessões ativas sem exigir login constante.
- **Dados Clínicos**: Informações importadas do AGHU relacionadas ao paciente e ao exame, que complementam a visão de rastreabilidade.
